  1. Correct by construction

    Anchored HealthKit queries keyed by sample UUID make duplicate rows and missed changes structurally impossible, and deletions flow downstream.

  2. Built for AI agents

    An open source MCP server and a hosted OAuth 2.1 relay let ChatGPT, Claude and Gemini query 115+ Apple Health data types. Every connection is approved on the phone.

    GitHub Actions macOS runners test, sign and upload every build with fastlane and the App Store Connect API, gated by the full test suite.

  4. Run like a product

    Listed in the official MCP Registry, a one-click Claude Desktop extension, subscriptions through StoreKit, and live dining menus for 46 universities.
